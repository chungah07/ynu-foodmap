# 🍜 YNU FoodMap - 영남대 맛집지도

영남대학교 재학생을 위한 **맛집 지도 앱**입니다. 정문/후문 기준으로 1km, 3km, 5km 반경 내 맛집을 지도에서 한눈에 볼 수 있어요!

## ✨ 주요 기능

- **🗺️ 지도 기반 검색** - 정문/후문 기준으로 반경 1/3/5km 맛집 확인
- **🍽️ 14개 기본 맛집** 데이터 내장 (영남대 주변 실제 식당들)
- **⭐ 별점 & 리뷰** - 직접 평점과 한줄평 남기기
- **📸 사진 첨부** - 식당 사진 URL 등록 가능
- **➕ 맛집 직접 추가** - 새로운 식당 발견하면 누구나 등록
- **🏆 랭크 시스템** - 리뷰 개수에 따라 칭호 획득!
  - 🌱 새내기 미식가 (0~4개)
  - 🔍 맛집 탐험가 (5~14개)
  - ⭐ 미식의 달인 (15~29개)
  - 👑 푸드 마스터 (30~49개)
  - 🏆 영남대 미식왕 (50개+)
- **👤 로그인** - 구글/애플/익명으로 가입 가능
- **✅ 혼밥 필터** - 혼자 밥먹기 좋은 곳 확인
- **🔍 검색** - 식당 이름, 메뉴로 검색
- **📱 반응형** - 모바일/PC 모두 지원

## 🚀 사용법

1. [GitHub Pages](https://chungah07.github.io/ynu-foodmap/) 에 접속
2. 정문/후문 선택 → 1km/3km/5km 거리 필터
3. 지도에서 마커 클릭 or 왼쪽 리스트에서 식당 선택
4. 별점 + 리뷰 남기기

## 🛠 기술 스택

- **Frontend**: HTML, CSS, JavaScript
- **지도**: Leaflet.js + OpenStreetMap
- **데이터 저장**: localStorage (브라우저)
- **배포**: GitHub Pages

## 🔥 Firebase 연동 가이드

현재는 `localStorage`로 동작하지만, Firebase를 연동하면:
- 실제 구글/애플 로그인
- 모든 유저가 공유하는 맛집 DB
- 실시간 리뷰/평점 업데이트

### Firebase 설정 방법
1. [Firebase Console](https://console.firebase.google.com/) 에서 새 프로젝트 생성
2. Authentication → Google/Apple 로그인 활성화
3. Firestore Database 생성 (테스트 모드)
4. 프로젝트 설정에서 Firebase SDK 정보를 `index.html`의 `firebaseConfig`에 입력
